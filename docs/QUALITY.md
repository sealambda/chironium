# Chironium Quality Tooling

Streamlined processes for running formatting, linting, and quality checks across both the Elixir/Phoenix backend and React/TypeScript frontend.

## Quick Reference

```bash
# Run all quality checks (no fixes).
./scripts/quality.sh

# Auto-fix formatting and linting issues.
./scripts/fix.sh

# Pre-commit checks (quality + tests).
./scripts/precommit.sh
```

## Why Biome?

We chose **Biome** over ESLint + Prettier for:

- **Single tool** - Replaces both ESLint and Prettier in one package
- **Performance** - 10-100x faster than ESLint + Prettier combined
- **Zero config drift** - Single `biome.json` instead of `.eslintrc` + `.prettierrc`
- **Import sorting** - Built-in organize imports (no extra plugin)
- **Tailwind class sorting** - Native `useSortedClasses` rule
- **Modern defaults** - Sensible rules for React 19, TypeScript 5.9+

## Architecture & Design Philosophy

### Fail-Fast Principle

Commands are ordered from **fastest → slowest** and **most critical → least critical**:

```txt
TypeScript (30-500ms) → Format Check (100ms) → Lint (500ms) → Dialyzer (30s+) → Tests (variable)
```

**Benefits:**

- Immediate feedback on critical issues (type errors, syntax)
- Don't waste time on slow checks if fast ones fail
- Better developer experience

### Security-First in CI

The `mix ci` alias runs `deps.audit` **first** to catch security vulnerabilities before anything else. If dependencies have known CVEs, the build fails immediately.

## Backend (Elixir/Phoenix/Ash)

### Available Mix Tasks

```bash
# Format code.
mix format

# Check formatting without changes.
mix format.check

# Run linter (Credo) and security scanner (Sobelow).
mix lint

# Auto-fix formatting.
mix lint.fix

# Full quality suite (compile, format, lint, security, dialyzer).
mix quality

# Pre-commit checks (quality + tests, no dialyzer).
mix precommit

# CI checks (security audit + quality + tests + dialyzer).
mix ci
```

### Tools Configured

- **mix format** - Elixir code formatter (`.formatter.exs`)
- **Credo** - Static code analysis and linting (`.credo.exs`)
- **Sobelow** - Security-focused static analysis (`.sobelow-conf`)
- **Dialyzer** - Type checking and analysis (`priv/plts/dialyzer.plt`)

**Files:**

- `.formatter.exs` - Formatter configuration (import deps, line length, etc.)
- `.credo.exs` - Linter rules (strict mode enabled, max line length 120)
- `.sobelow-conf` - Security scanner configuration
- `.dialyzer_ignore.exs` - Known false positives to ignore

## Frontend (React/TypeScript)

### Available pnpm Scripts

```bash
cd assets

# Format code.
pnpm run format

# Check formatting without changes.
pnpm run format:check

# Run Biome linter.
pnpm run lint

# Auto-fix linting issues.
pnpm run lint:fix

# Run all Biome checks (format + lint + imports).
pnpm run check

# Auto-fix all Biome issues.
pnpm run check:fix

# Run TypeScript type checking.
pnpm run typecheck

# Full quality suite (check + typecheck).
pnpm run quality

# Pre-commit checks (same as quality).
pnpm run precommit
```

### Tools Configured

- **Biome 2.3** - Unified formatter, linter, and import organizer
- **TypeScript 5.9** - Type checking

**Files:**

- `assets/biome.json` - Biome configuration (format, lint, import sorting)
- `assets/tsconfig.json` - TypeScript compiler options

### Biome Configuration Highlights

The `biome.json` includes:

```json
{
  "linter": {
    "rules": {
      "a11y": { "recommended": true },
      "correctness": { "noUnusedImports": "warn" },
      "suspicious": { "noExplicitAny": "warn" },
      "nursery": {
        "useSortedClasses": {
          "level": "warn",
          "options": {
            "functions": ["clsx", "cn", "cva", "twMerge"]
          }
        }
      }
    }
  },
  "assist": {
    "actions": {
      "source": { "organizeImports": "on" }
    }
  }
}
```

**Key features:**

- **Tailwind class sorting** - Automatically sorts CSS classes in `className`
- **Import organization** - Groups and sorts imports automatically
- **A11y rules** - Accessibility warnings for better UX
- **React hooks** - Exhaustive dependencies warnings
- **Security** - No dangerous innerHTML warnings

### Files Ignored

- `src/routeTree.gen.ts` - Auto-generated by TanStack Router
- CSS files - Tailwind uses non-standard directives (`@apply`, `@layer`)
- `node_modules`, `dist`, `public`, `vendor` directories

## Root-Level Scripts

Located in `./scripts/`:

### `./scripts/quality.sh`

Runs all quality checks for both backend and frontend:

**Backend:**

1. Compile with warnings as errors
2. Check for unused dependencies
3. Format check
4. Credo (linter)
5. Sobelow (security)

**Frontend:**

1. Biome check (format + lint + imports)
2. TypeScript type checking

**Exit behavior:** Fails on first error (strict mode).

### `./scripts/fix.sh`

Auto-fixes all auto-fixable issues:

**Backend:**

1. `mix format` - Auto-format all Elixir code

**Frontend:**

1. `pnpm run check:fix` - Auto-fix format, lint, and import sorting

**Exit behavior:** Continues even if some steps fail, shows all issues.

### `./scripts/precommit.sh`

Runs comprehensive pre-commit checks:

**Backend:**

- `mix precommit` (quality + tests, no dialyzer)

**Frontend:**

- `pnpm run precommit` (check + typecheck)

**Exit behavior:** Fails on first error. Tests must pass.

## Typical Workflow

### During Development

```bash
# Make code changes...

# Auto-fix formatting and linting.
./scripts/fix.sh

# Verify everything passes.
./scripts/quality.sh
```

### Before Committing

```bash
# Run full pre-commit checks.
./scripts/precommit.sh

# Commit when all checks pass.
git commit -m "feat(client): Add new feature"
```

### Backend-Only Changes

```bash
# Auto-fix.
mix format

# Check quality.
mix lint

# Or run everything including tests.
mix precommit
```

### Frontend-Only Changes

```bash
cd assets

# Auto-fix everything.
pnpm run check:fix

# Check quality.
pnpm run quality

# Build to verify.
pnpm run build
```

## IDE Integration

### VS Code / Cursor

Install the **Biome** extension for automatic formatting on save:

- **Biome**: biomejs.biome

Add to `.vscode/settings.json`:

```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "biomejs.biome",
  "editor.codeActionsOnSave": {
    "source.organizeImports.biome": "explicit"
  },
  "[elixir]": {
    "editor.defaultFormatter": "elixir-lsp.elixir-ls"
  },
  "[typescript]": {
    "editor.defaultFormatter": "biomejs.biome"
  },
  "[typescriptreact]": {
    "editor.defaultFormatter": "biomejs.biome"
  },
  "[json]": {
    "editor.defaultFormatter": "biomejs.biome"
  }
}
```

## Configuration Files

### Backend

| File                   | Purpose                   | Key Settings                                      |
| ---------------------- | ------------------------- | ------------------------------------------------- |
| `.formatter.exs`       | Elixir code formatter     | Import deps for plugins, line length              |
| `.credo.exs`           | Static analysis & linting | Strict mode, max line length 120                  |
| `.sobelow-conf`        | Security scanner          | Security rules for Phoenix/Plug                   |
| `.dialyzer_ignore.exs` | Dialyzer false positives  | Known warnings to suppress                        |
| `priv/plts/`           | Dialyzer PLT cache        | Precompiled type info (speeds up subsequent runs) |

### Frontend

| File                   | Purpose                           | Key Settings                                |
| ---------------------- | --------------------------------- | ------------------------------------------- |
| `assets/biome.json`    | Format, lint, import organization | Tailwind sorting, a11y, React hooks         |
| `assets/tsconfig.json` | TypeScript compiler               | Strict mode, React JSX, paths configuration |
| `assets/package.json`  | npm scripts                       | All quality scripts defined here            |

### Root-Level

| File                   | Purpose                 | Covers             |
| ---------------------- | ----------------------- | ------------------ |
| `.editorconfig`        | Editor settings         | All file types     |
| `scripts/quality.sh`   | Unified quality checks  | Backend + Frontend |
| `scripts/fix.sh`       | Unified auto-fix        | Backend + Frontend |
| `scripts/precommit.sh` | Pre-commit verification | Backend + Frontend |
| `package.json`         | Workspace scripts       | pnpm workspace     |
